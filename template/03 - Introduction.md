Welcome to the [Company] internal style guide!

This guide helps everyone on the team write docs that are clear, consistent, and easy to find. You don't need to be a professional writer to use it. Most of the time, you only need the first two sections.

## How to use this guide

- **Start with §01 Quick Rules.** It covers the rules that come up most, on one page.
- **Before you publish anything, run through §02,** the editing checklist.
- **Look up everything else** when a question comes up. You don't need to memorize it.

## Who this guide is for

Anyone who writes or updates [Company] internal docs, including [knowledge base articles, processes, onboarding docs, and team updates].
