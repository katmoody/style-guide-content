# 08 - Inclusive language

Inclusive language is clear language. It keeps any reader from feeling like the docs weren't written for them.

> **Template note:** Notes like this are instructions for whoever sets up the guide. **Delete them before you publish.** (How to customize: §00.)

> **Customize (D2):** If your company already has inclusive language guidelines, link them here and keep only what they don't cover.

## Writing about people

- **Use gender-neutral words.** "Everyone," not "guys." "Chairperson," not "chairman."
- **Use "they" when you don't know someone's gender,** or rewrite with "you" or a role: "the requester."
- **Focus on the person, not the condition,** and only mention a disability when it's relevant. "Uses a wheelchair," not "confined to a wheelchair."
- **When writing about a real person,** use the words and pronouns they use for themselves.

## Idioms to skip

Some common phrases are violent or ableist, and most don't translate well anyway (see §09).

| Instead of | Try |
| --- | --- |
| sanity check | quick check, confidence check |
| crazy, insane | surprising, unexpected |
| blind spot | gap, oversight |
| kill two birds with one stone | do two things at once |
| pull the trigger | go ahead, decide |

Technical commands are different. If the command is `kill`, write `kill`.

## Technical terms we've retired

| Instead of | Use |
| --- | --- |
| whitelist, blacklist | allowlist, blocklist |
| master/slave | primary/replica |
| dummy value | placeholder value |
| grandfathered | legacy |
| [Your retired term] | [What to use instead] |

If readers might not recognize the new term yet, mention the old one once, in parentheses: "Add the address to the allowlist (sometimes called a whitelist)." Then use the new term from there on.

## Examples and names

- **Use a mix of names** in examples, from different cultures and backgrounds.
- **Avoid stereotypes,** like making every developer "he" or every assistant "she."
- **Don't assume** everyone celebrates the same holidays, has the same family setup, or lives in the same country.
