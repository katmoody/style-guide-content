## Our references

- [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/): Our main reference
- [The Chicago Manual of Style](https://www.chicagomanualofstyle.org/): Grammar and punctuation (subscription required; the [Q&A pages](https://www.chicagomanualofstyle.org/qanda/latest.html) are free)
- [Merriam-Webster](https://www.merriam-webster.com/): Spelling
- [Google developer documentation style guide](https://developers.google.com/style): A good second opinion, especially for developer docs

## Writing tools

- [Grammarly](https://www.grammarly.com/) and [ProWritingAid](https://prowritingaid.com/): Grammar and spelling checks (free versions have limits)
- [Hemingway Editor](https://hemingwayapp.com/): Readability
- [Capitalize My Title](https://capitalizemytitle.com/): Checks title and heading capitalization in different styles
- [Vale](https://vale.sh/): Checks docs against style rules automatically, for teams that keep docs in GitHub or GitLab
