# 09 - Writing for non-native English readers

Many of our teammates read English as a second (or third) language, and some read our docs through translation tools. Writing for them makes docs clearer for everyone.

> **Template note:** Notes like this are instructions for whoever sets up the guide. **Delete them before you publish.** (How to customize: §00.)

> **Customize (B2):** If very few readers speak English as a second language, you can shorten this section, but keep the rules. Translation tools benefit from them too.

## Write for readers and translation tools

- **Keep sentences short.** One idea per sentence.
- **Use common words.** "Use," not "utilize." "Help," not "facilitate."
- **Skip idioms, slang, and cultural references.** They don't translate.
  - **Instead of:** The launch hit it out of the park.
  - **Try:** The launch went very well.
- **Keep small words that make meaning clear,** like "that": "Make sure *that* the file is saved."
- **Use the same word for the same thing,** every time. If you call it a "workspace" once, don't call it a "project" later (see the word list in §06).
- **Save humor and sarcasm for chat,** not instructions. They're easy to misread.
- **Write dates with the month spelled out,** and define acronyms on first use (see §06).

## Resources for writers

Writing in a second language is hard, especially when you're writing for work. These free and low-cost resources can help:

- [British Council LearnEnglish: Writing](https://learnenglish.britishcouncil.org/skills/writing): Lessons and model texts by level
- [Plain English](https://plainenglish.com/): English lessons based on current events
- [The Punctuation Guide](https://www.thepunctuationguide.com/): Clear explanations of every punctuation mark
- [Hemingway Editor](https://hemingwayapp.com/): Flags long, hard-to-read sentences
